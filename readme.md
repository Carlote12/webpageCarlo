# Personal Web Page

## Idea
My idea for creating this personal website was to let people get to know me a little better, reach more people, and learn new things.

## Challenges
Translation:To solve this problem, I learned many new things, like how to use JSON. Thanks to this, I was able to have all the texts translated, and they translate as soon as I press the button. It was also a difficult challenge to solve, but very entertaining!
Arrange images:This one wasn't too difficult, but it was also fun because when I was arranging them, I had to make sure I was placing them correctly, and other times, due to a typo, everything would disappear or become enormous XD
